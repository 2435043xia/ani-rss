# TMDB 对齐订阅：季、偏移、路径和重命名

## 目的

订阅编辑里增加一个按钮。它按 TMDB 填写季和集数偏移，按 TMDB 名填写重命名模板，并在已接入的 Emby 里找到同一部，把替换后的目录写入自定义路径。订阅标题保持不动。

现有的「使用 TMDB」仍然只把标题改成 TMDB 名，这个按钮不替代它。

点按钮先弹出预览。确认后才把结果写进当前订阅编辑表单，并随这条订阅现有的保存落盘。取消什么都不改。不另做一套保存接口。

## 季和偏移

只使用主 RSS 里发布日期最早的一条，用这条自己的集号和发布日期。

- 发布日期相同的有多条时，取集号更小的那条，预览里写明用了哪一条。
- 已经选了剧集组时，在该组的集里比较 `air_date`。没选剧集组时，在这部剧的普通季里比较。
- 只比较日期，取相差天数最小的一集。两集一样近时，预览把两集都列出来，选中一集之后才能确认。
- 季 = 这一集的 `season_number`。
- 偏移 = 这一集的 `episode_number` − 这条 RSS 的集号。

RSS 第 25 集对上 TMDB 第 1 季第 25 集时，预览是季 1、偏移 0，试算文件名是 `S01E25`。

只改订阅自己的偏移。备用 RSS 各自的偏移保持原样。

## 重命名模板

确认后打开自定义重命名。模板由 TMDB 名本身和季、集占位符组成：

```text
葬送的芙莉莲 S${seasonFormat}E${episodeFormat}
```

这里写入 TMDB 名的文字，不用 `${title}`。`${title}` 展开后仍是订阅标题。

## 自定义路径

查找范围是媒体库管理里每一条已填写地址和密钥的 Emby。只比较 TMDB id。没有 id 命中时，再比较 TMDB 名。路径替换不参与查找。

有 TMDB id 命中时，只列出这些命中。每条显示 Emby、剧名、原始路径、替换后的路径。只有一条时默认选中。有多条时，选中一条之后才能确认。

一条都没有，或该台 Emby 请求失败时，预览写明原因，自定义路径改用全局下载路径模板：标题换成 TMDB 名，季用这次算出的季。预览同时给出模板和最终路径。

确认后打开自定义路径。有 Emby 时，写入替换后的目录，不再追加 `Season` 子目录。没有 Emby 时，写入上面按 TMDB 名生成的路径。

## 路径替换规则

规则放在媒体库管理里每一条 Emby 下面，随现有配置保存。一条规则是两段文字：Emby 前缀，以及对应的 ani-rss 前缀。

有多条时，用匹配得最长的前缀，只替换一次，不做连环替换。前缀末尾多一个或少一个斜杠，按同一条处理。

例如规则 `/volume1/anime` → `/mnt/smb/downloads`。Emby 目录 `/volume1/anime/葬送的芙莉莲/Season 1` 变成 `/mnt/smb/downloads/葬送的芙莉莲/Season 1`。

没有规则命中时，预览显示 Emby 原始路径，仍可以确认写入这条原始路径。

## 预览

预览按这个顺序显示：

1. 主 RSS 最早的一条：标题、集号、发布日期。
2. 对上的 TMDB 集：季号、集号、播出日期、集标题。
3. 现在的季和偏移，以及将要写成的季和偏移，加一行试算文件名。
4. 重命名模板。
5. Emby 候选，或未找到时的 TMDB 路径。
6. 冲突说明。

主 RSS 为空、最早一条没有日期或集号、TMDB 对不上，因而季和偏移算不出来时，确认不可用，这次不写入。

新的「标题 + 季」与另一条订阅重复时，写明是哪一条，确认不可用。这与现有的「订阅标题重复」是同一条限制。

订阅还没有 TMDB 时，用当前标题查询，预览里显示查到的名称和 id。确认后写入这份 TMDB 信息。原来已有的剧集组 id 保留。标题仍然不变。

## 确认后写入的字段

- 季
- 集数偏移
- 新查到的 TMDB 信息
- 自定义重命名开关和模板
- 自定义路径开关和路径

保持不动的有：订阅标题、备用 RSS 的偏移、「使用 TMDB」按钮的行为。

## 代码位置

计算和访问外部服务分开。预览接口只计算，不保存订阅。

- `EpisodeAlignUtil`：选最早的 RSS、选最近的 TMDB 集、计算偏移。不访问网络。
- `PathReplaceUtil`：按最长前缀替换一次。不访问网络。
- `TmdbAlignService`：组装预览。TMDB 集信息走现有的 `TmdbUtils`。Emby 剧集查询加在 `EmbyRefreshService`，请求 `GET /emby/Items`，带上 `ProviderIds` 和 `Path`。地址、密钥和媒体库来自现有的 Emby 配置。
- `ThemoviedbController` 增加 `POST /api/previewTmdbAlign`。
- `NotificationConfig` 增加每条 Emby 的替换规则列表。媒体库管理的 `EmbyLibraryItem.vue` 编辑这些规则。
- 订阅编辑 `AniView.vue` 增加按钮。新对话框 `TmdbAlignPreview.vue` 显示预览。`http.js` 增加对应请求。

媒体库管理页面已经在当前工作区，尚未提交。实现时在那一页上补替换规则，不另开一套 Emby 配置。

## 测试

为 `EpisodeAlignUtil` 和 `PathReplaceUtil` 加不启动整个应用的单元测试：

- 更早的发布日期胜出；日期相同则集号更小的胜出。
- 相差 1 天的集胜出相差 3 天的集；相差天数相同则返回两集。
- RSS 第 25 集对上第 25 集时偏移为 0；对上第 1 集时偏移为 -24。
- 最长前缀胜出；末尾斜杠不影响；没有命中时返回原路径；一条规则只替换一次。
- 有 TMDB id 命中时，同名的其他剧不进入候选。
- 标题加新季与另一条订阅重复时，预览不允许确认。

Emby 和 TMDB 的网络请求不放进单元测试。界面在实现完成后，用一条已有订阅打开预览，核对季、偏移、模板和路径，再取消，确认订阅未被改写。

## 打包

功能实现并验证之后再打包镜像。镜像推到 `registry.888987.xyz`。tag 使用新的，不覆盖当前正在运行的 tag，也不使用 `latest`。具体 tag 在打包时按当时版本号加上 `-tmdb-align`。

## 不做

- 不改订阅标题。
- 不改备用 RSS 的偏移。
- 不从 Emby 文件名反推重命名模板。
- 不按路径查找 Emby 剧集。
- 不在 Emby 目录后面自动追加季文件夹。
- 不改 qBittorrent 登录，也不改 Emby 刷新和 Webhook 的现有行为。
